## 🚀 Getting started

### 📦 Install

Requisitos: 
- Node.js 18.18 or later
- Git

```bash
git clone git@github.com:petsi-each/nomedoprojeto.git
cd nomedoprojeto
npm i
```

<br/>

### ⚙️ Running

- Prod:
```
npm run build
```


- Dev:
```
npm run dev
```
Access http://localhost:3000
